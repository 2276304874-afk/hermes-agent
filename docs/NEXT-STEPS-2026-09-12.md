## 2. 各步骤详情

### A1 · 停止裁判"乐观停止"复测
- **功能 / 解决的问题**：验证 P1-3 的确定性裁判在真实「打转 / 重复试错」场景下能正确报出。审计原判据"自主任务不再乐观停止"**尚未复测**，是已完成工作的唯一验证缺口。
- **预期产出**：`test/stopjudge.test.js` 新增 2–3 个"反例对话"用例（模拟同一工具调用重复 / 同结果重复，断言触发 D1 warn 或 D2 hard）；`docs/checkpoints.md` 补一句结论"已用固定反例集复测通过"。
- **风险 / 前置依赖**：纯验证、无破坏性。若复测暴露漏报，回到 `lib/stopjudge.js` 调阈值（可能升 hard 或降 `dupLimit`）——但判据设计原则是**高精度低召回**，调参需谨慎，避免误报让提示失去信任。

### A2 · 配置真源落盘 `setup.sh`（幂等补写）★ 风险闭环 ✅ 已实现
- **功能 / 解决的问题**：`checkpoints.*` 与 `terminal.cwd` 写在 `~/.hermes/config.yaml`（仓库外，且同文件含 gateway key），**换机重装不会自动复现**——此前靠 `npm run health` §10 三条断言防漂移，但"重装即复现"未实现。现已在 `setup.sh` 加 `[2c]` 段幂等补写。
- **预期产出**：`setup.sh` `[2c]` 段——若 `config.yaml` 缺 `^checkpoints:` / `^terminal:` 则先 `cp` 备份再追加（不覆盖已有值），含自检回显。补写后 `healthcheck` §10 即从"报警"变为"自愈"。语法 `bash -n` 通过；幂等性已用空配置模拟验证（首次补写、二次跳过，各块仅 1 次）。
- **风险 / 前置依赖**：
  - ⛔ **launchd 权限边界**：我的 shell 里跑 `setup.sh` 必 EIO 5，需**你在 Terminal.app 手动跑一次 `bash setup.sh`** 才能完整验证（注册后 `launchctl kickstart` 我可用）。本机 config 已含两项 → 实跑会是"跳过"分支，不改动现有认证。
  - 改动同含 gateway key 的文件，脚本已内置 `cp config.yaml config.yaml.bak-<时间戳>` 备份，增量只增不减。

### B1 · P1-4 `curator adopt` 技能治理
- **功能 / 解决的问题**：192 个技能目录待治理（去重 / 标注 `agent-created` / 清理孤儿 `~/.hermes/.skill_embeddings.json` 853KB）。
- **预期产出**：`hermes curator` 跑通且 `agent-created > 0`；孤儿 embeddings 文件清理；技能清单瘦身报告。
- **风险 / 前置依赖**：⚠️ **先读 `~/.hermes/hermes-agent/.../curator*.py` 确认 `adopt` 的副作用范围**（会改哪些技能 frontmatter / 目录）；**务必先在技能副本上 dry-run**，确认不破坏在用技能。记忆提示"agent-created=0 时零作用"——可能需先 adopt 才生效，故 adopt 行为需先摸清。

### B2 · P1-2 结构化任务清单（可选，收益已降）
- **功能 / 解决的问题**：每轮任务以结构化形式存在（目标 / 验收条件 / 已完成 / 待办），作为裁判补充、交付摘要依据、压缩续聊依据。
- **预期产出**：`lib/` 固定模板解析 + 前端渲染 + 单测；**最小版**（不抄 MiMo 的 validator/retry/reconcile 三件套，审计 §9 已否决）。
- **风险 / 前置依赖**：小模型易漂，需固定模板 + 单测约束；**已因确定性裁判而不再是 P1-3 的前置**，优先级下调，可缓做。

### C1 · P2-2 工作目录前导
- **功能 / 解决的问题**：治 `-z --in` 不约束 `terminal.cwd` 的隐患（目前 cwd 真源有两处：config 的 `terminal.cwd` + 任务前导），避免 `-z` 路径落 `$HOME`。
- **预期产出**：`lib/routes/chat.js` 每条任务注入固定前导「工作目录：<绝对路径>」；与项目上传后缀措辞统一。
- **风险 / 前置依赖**：两处措辞冲突需统一；纯注入，低破坏性。

### C2 · P2-1 拦截反馈可读化
- **功能 / 解决的问题**：被安全拦截 / 拒绝时，模型拿到的是原始错误 → 可能卡死或把原始错误吐给用户。
- **预期产出**：`lib/safety.js` 在被拦时返回"该路径被策略拒绝，请换方案"类**模型能读懂的反馈**；测试覆盖。
- **风险 / 前置依赖**：保留 TTL 放行语义（超时转拒绝与"放手自主"目标潜在冲突），靠 7 天上限兜底；**不涉及放宽安全边界**。

### D1 · P2-3 `proactive_prune` 调参
- **功能 / 解决的问题**：工具结果占位主动回收，缓解 32K 窗口压力（`proactive_prune_min_result_chars: 8000` / `min_reclaim_tokens: 4096`）。
- **预期产出**：量化收益报告 + 配置调整。
- **风险 / 前置依赖**：⚠️ 先量化收益，别凭感觉调；改动触及上下文预算红线（见 MEMORY §上下文预算红线：system 27K + tools 37K + 索引 14K ≈ 17K tok 起步，32K 仅够用）。

### D2 · P2-4 前端模块化（UiDesigner 相关）
- **功能 / 解决的问题**：`app.js` 1994 行单文件，按域拆分提升可维护性。
- **预期产出**：拆为若干 ES 模块或 IIFE 段，功能与外观不变。
- **风险 / 前置依赖**：⚠️ 触碰前端三不变量（① `head` 内联主题+版本戳不可外移；② `/app.js` 在 body 末不加 `defer`/`async`；③ 不改 ES module），需 `npm run ui` 全绿 + 不变更。收益/风险比一般，**缓做**。

### D3 · 模型对比实验（挂起）
- **功能**：7B 模型对比（复用 `scripts/model-bench.js` / `model-bench-agent.sh`）。
- **依赖**：需能访问 HF / ModelScope 下载 GGUF；当前 `github.com:443` 被阻断，HF 大概率不通。
- **诚实预期**：4B → 7B 是改善不是跃迁；量级差距需量级方案，工程补不了。建议网络前提满足后再做。
