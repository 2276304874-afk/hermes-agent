# 豆包"M4 16G 本地 AI Agent 全套方案" 深度核验报告

## 概述
本报告对一份由外部 AI（豆包）生成的《Mac M4 16G 纯免费本地 AI Agent 全套落地汇总文档》进行了多来源、带引用的深度事实核验，并与用户当前实际项目（赫尔墨斯特工：本地 Ollama + Hermes v0.21.0 + Web 控制台）逐条对比。研究完成于 2026-09-06。

## 目录
1. **执行摘要**（1 页）- 关键发现与建议
2. **完整报告** - 11 条声明的逐条核验 + 现状对比 + 修正记录
3. **数据与统计** - 关键事实与数字
4. **来源** - 完整引用（含 A-E 质量评级）
5. **研究笔记** - 4 个并行研究智能体的原始发现
6. **附录** - 方法论与局限性

## 一句话结论
豆包文档**架构思路成立，但命令层大面积失真**：11 条核心声明中仅 3 条完全属实、2 条部分属实、6 条不实（含 2 个不存在的模型标签、Hermes 被误写为 npm 项目、配置文件结构全错）。照抄会直接失败或破坏现有可运行环境。

## 后续动作建议（详见完整报告第 8 节）
- 采纳：OpenCode 编码子 Agent（唯一真增量）
- 修复：双 plist 端口冲突 → 14b 派生模型接通 → cron 网关
- 配置：OLLAMA_KEEP_ALIVE 由 120s 放宽（agent 场景建议 10-30 分钟或 -1）
