## P0 升级：SSE 实时流 + 工具时间线（15:00-15:55，已完成并端到端验证）

### 方案
CLI 是缓冲输出（无 token 级流式），但 Hermes 把每个会话的消息**边跑边写**进 `~/.hermes/state.db` 的 `messages` 表（`role/tool_name/content/tool_calls/display_kind/reasoning/id/timestamp`，id 单调递增）。→ 后端 spawn CLI 后以 600ms 轮询只读该表，新增行即时转 SSE 事件推前端，实现"伪流式 + 工具实时可视化"。

### 事件协议（已实测通过，关键）
- `ready {runId}` → `session {sessionId}`（新会话 id 靠对比 baseline 自动识别）→ 逐条 `msg {id,role,toolName,content,toolCalls,displayKind,reasoning,ts}` → `done {elapsed,sessionId}`
- 真实运行中的行序列（terminal 工具实测）：assistant 行带 `toolCalls`（JSON 字符串：`[{function:{name,arguments:"{\"command\":\"...\"}"}}]`，arguments 是**转义 JSON 字符串**需二次 parse）→ role=tool 行（`content` 是 JSON 字符串 `{"output","exit_code","error"}`，需 parse 取 output）→ assistant 终答行。
